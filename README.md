# DST Upgraded Backpack

A Don't Starve Together mod that expands and upgrades the functionality of backpacks.

The goal of this mod is to turn backpacks from simple storage items into upgradeable equipment. Backpacks can be upgraded to increase their storage capacity and unlock module slots. Different modules can then be installed into these slots to provide additional functionality.

## Features

### Backpack Upgrade System

Backpacks can be upgraded up to **5 times**.

A backpack starts with **12 inventory slots**, and each upgrade adds an additional **12 slots**.

| Upgrade Level | Backpack Slots |
| --- | ---: |
| Base | 12 |
| +1 | 24 |
| +2 | 36 |
| +3 | 48 |
| +4 | 60 |
| +5 | 72 |

Upgrading a backpack can also unlock additional **module slots**, allowing the backpack to gain new abilities.

### Module Slot System

Backpacks can be customized by installing different modules into their module slots.

Each module provides a different function or passive effect, allowing players to customize their backpack for different purposes.

Currently planned modules include:

#### Spatial Module

Allows items stored inside the backpack to **stack without the normal stack-size limit**.

#### Alchemy Engine Module

While the backpack is equipped, the player gains access to all recipes normally unlocked by an **Alchemy Engine**.

The effect is only available while the backpack is being worn.

#### Ancient Pseudoscience Module

While the backpack is equipped, the player gains access to recipes normally unlocked by the **Ancient Pseudoscience Station**.

The effect is only available while the backpack is being worn.

## Planned Features

The mod is currently in development.

More backpack upgrades, modules, balance adjustments, and customization options may be added as development continues.
